Clip Studio Brush Importer (sut2kpp)

Tools > Scripts > Import Clip Studio Brushes (.sut)... converts Clip Studio Paint sub tool files to Krita brush presets. The presets are written as one resource bundle into the Krita resource folder; restart Krita to see them.

"CSP Brush engine" needs a Krita build with the CSP Brush paint op. The other choice makes presets for the Pixel and Color Smudge engines of stock Krita, which follow the brush less closely.

Only import brushes you have the right to use. A converted preset contains the tip images of the brush.
