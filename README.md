This plugin converts .sut files (Clip studio brush) into .kpp brushes (Krita brushes).

It is designed to be used with a custom Krita build that has a CSP-like brush engine (https://github.com/hwhw3195/comickrita/releases/tag/v5.3.4-ck1.0). It does have a legacy mode to export to standard krita paint engine, but the fidelity of the brushes are going to be much worse.

**Only use the converter on brushes you have the right to use.**
